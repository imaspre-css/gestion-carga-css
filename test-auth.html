🧪 Prueba aislada: Supabase Auth + Azure AD

Esta página no toca la app real — solo valida que la conexión Azure AD ↔ Supabase funciona antes de integrarla en login.html.

Sin sesión activa todavía.

1. Sube este archivo como test-auth.html a la raíz del repo (junto a los demás .html)
2. Añade su URL completa a Supabase → Authentication → URL Configuration → Redirect URLs:
https://imaspre-css.github.io/gestion-carga-css/test-auth.html
3. Ábrela, pulsa "Iniciar sesión con Azure" → deberías ver la pantalla de login de Microsoft → tras entrar, volverás aquí con tu sesión mostrada abajo
